#  Monitor de Tráfego de Rede com Geolocalização

Script em Python que utiliza a biblioteca **Scapy** para capturar pacotes de rede IP em tempo real, identificar os IPs de destino e consultar a cidade/país de origem usando uma API pública.

---

##  Pré-requisitos

O Scapy precisa interagir diretamente com a placa de rede. Portanto, certifique-se de executar o script com privilégios elevados:
- **Linux / macOS:** `sudo`
- **Windows:** Prompt de Comando ou PowerShell como **Administrador**.
